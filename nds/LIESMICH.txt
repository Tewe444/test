SKY DASH FUER DEN NINTENDO DS
=============================
Rhythmus-Jump-Spiel mit der Physik deiner Browser-Version (physics.js, 1:1 uebernommen)
und den Modi von Geometry Dash (Advance). Der Quellcode steht in source/.

MODI UND OBJEKTE
----------------
Wuerfel, Schiff, Wave (bisher) + NEU: Ball, UFO, Mini-Groesse.
Tempo-Portale: 0.5x, 1x, 2x, 3x, 4x (8.37 / 10.39 / 12.91 / 15.6 / 19.2 Bloecke pro Sekunde).
Ringe: gelb, rosa, rot, blau.  Pads: gelb, rosa, rot.  Dazu Schwerkraft-Portale, Muenzen, Saegen.
Level: deine 5 Level + 3 neue (6 Ball Rush, 7 UFO Skies, 8 Mini Mania).

STEUERUNG
---------
Springen / Steigen: A, B, X, Y, Kreuz oben oder Touchscreen antippen (halten = immer wieder).
Ball: tippen = Schwerkraft drehen.  UFO: jedes Tippen = ein Huepfer.
START = Pause.   Uebungsmodus: L = Checkpoint setzen, R = letzten loeschen.
Menue: Touchscreen oder Kreuz (links/rechts = Level, A = Start, B = zurueck).

EIGENE FIGUR
------------
Menue -> FIGUR (oder ICON -> ZEICHNEN): 16x16-Pixel-Zeichner mit 15 Farben und Spiegel-Modus.
Die Figur ist dein Wuerfel. Wird auf der SD-Karte gespeichert (skydash/char.bin).

SD-KARTE (SPEICHERN, EIGENE FIGUR, LEVEL TEILEN)
------------------------------------------------
Die SD-Karte wird NICHT automatisch benutzt, denn das Starten des Dateisystems (fatInitDefault) kann
bei manchen Emulatoren und Karten ohne passenden Treiber haengen. Im Menue oben rechts "SD AN" tippen:
erst dann wird die Karte gesucht (davor erscheint eine Meldung). Haengt das Bild dort, Spiel neu starten
und SD nicht aktivieren - Spielen, Editor und Figuren-Zeichner gehen auch ohne SD (nur ohne Speichern).
Emulator: DeSmuME braucht eine DLDI-gepatchte ROM (make dldipatch), melonDS kann einen SD-Ordner nutzen.

LEVEL-EDITOR
------------
Menue -> EDITOR. Auf den unteren Bildschirm tippen / ziehen = Objekt setzen.
  Kreuz hoch/runter = Werkzeug waehlen (alle Objekte, Portale, Ringe, Pads)
  Kreuz links/rechts = scrollen, L/R = schnell scrollen
  A = Radierer an/aus     B = letztes Objekt zurueck
  X = Testspiel von vorne    Y = Testspiel ab der aktuellen Stelle (als Wuerfel)
  START = auf SD speichern   SELECT = speichern + Menue   L+R+B = alles loeschen
Gespeichert wird (mit aktivierter SD) in  SD:/skydash/levels/mylevel.txt

LEVEL MIT FREUNDEN TEILEN
-------------------------
Jede .txt-Datei in SD:/skydash/levels/ erscheint automatisch am Ende der Levelauswahl.
Zum Teilen: Datei mylevel.txt (vorher am besten umbenennen) auf die SD-Karte deines Freundes
in skydash/levels/ kopieren. Dasselbe Textformat nutzt auch dein PC-Tool und skydash_konverter.html.
Auf der DS gelesen werden: name, diff, stars, speed, bpm, song, length, color und alle Objekte.
NICHT gelesen werden def/use/loop (Muster) - die gibt es nur im PC-Tool fuer die eingebauten Level.

BAUEN
-----
Variante A (ohne Installation): siehe START_HIER.txt (GitHub baut die .nds).
Variante B: devkitPro mit "nds-dev" installieren, dann in diesem Ordner:  make
Eingebaute Level aendern: levels/*.txt bearbeiten, build_levels.sh (oder .bat) starten, dann make.

HINWEIS ZUM TEMPO
-----------------
Das Spieltempo haengt an der Hardware-Uhr der DS, nicht an der Bildrate: Auch wenn die DS
einmal weniger als 60 Bilder pro Sekunde schafft, laeuft das Spiel in der richtigen Geschwindigkeit.
Unten im Spiel steht links eine FPS-Anzeige. Sie zeigt, wie fluessig es gerade laeuft.

WAS ICH GEPRUEFT HABE - UND WAS NICHT
-------------------------------------
Geprueft (am PC): Die Spielphysik liefert mit denselben Eingaben dieselben Positionen und denselben
Todes-Frame wie deine physics.js (Level 1-5). Die neuen Level 6-8 sind mit der neuen Physik
durchspielbar (Test-Bot). Alle Bildschirme wurden gegen einen PC-Ersatz fuer libnds gerendert.
NICHT geprueft: Lauf auf einer echten DS. Bei einem Absturz zeigt die DS einen Fehlerbildschirm (libnds-Exception-Handler) - Foto davon hilft mir sehr.
NICHT geprueft: Lauf auf einer echten DS, die Tonausgabe, das Speichern auf SD, Geschwindigkeit
auf der Hardware. Ball, UFO, Mini und die rosa/roten Ringe nutzen Werte aus Geometry Dash Advance,
umgerechnet auf deine Schwerkraft - sie fuehlen sich nur annaehernd wie im Original an.
Klingt die Musik 3 Oktaven zu tief: in source/audio.h  PSG_MUL  von 1 auf 8 setzen.
