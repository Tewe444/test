So bekommst du die fertige skydash.nds (ohne etwas zu installieren)
===================================================================
1. Auf github.com ein neues Repository anlegen (oder dein Sky-Dash-Repository nehmen).
2. Den INHALT dieses Zips hochladen: die Ordner ".github" und "nds".
   (Wichtig: der Ordner ".github" muss mit hoch, der Punkt am Anfang gehört dazu.)
3. Oben auf "Actions" klicken. Der Bau startet von selbst (ca. 1-2 Minuten).
   Falls nicht: "skydash.nds bauen" -> "Run workflow".
4. Fertigen Lauf anklicken, unten bei "Artifacts" auf "skydash-nds" klicken.
   GitHub packt sie in ein Zip: darin liegt skydash.nds.

Lokal bauen geht auch: siehe nds/LIESMICH.txt
